# Agnes 生成工作台

一个本地运行的 Web 应用，将 [Agnes AI](https://apihub.agnes-ai.com) 的图像与视频生成 API 封装为可视化操作界面。

**当前版本：`v0.1`**（2026-10-17 发布）· 版本更新记录见文末「版本记录」

当前阶段：**本地使用**（架构上已预留部署上线的条件，见下文「部署注意」）。

---

## 功能

### 图像生成（已可用，全部实测通过）

| 功能   | 说明                                |
| ---- | --------------------------------- |
| 文生图  | 文字描述生成图像，1K–4K 四档尺寸 × 8 种宽高比      |
| 图生图  | 基于单张输入图做转换、重绘、风格化编辑               |
| 多图合成 | 2–6 张参考图组合生成，按上传顺序在提示词中以「第 N 张」指代 |

### 视频生成（暂不可用）

文生视频、首尾帧生视频、图生视频、音频参考四个功能已在导航中预留入口（置灰）。  
未开放原因：Agnes 视频推理队列持续拥堵（`503 video_queue_full`），且本地图片能否以 Data URI 形式直接喂给视频接口尚待实测。队列恢复后即可补齐。

## 快速开始

### 1. 创建虚拟环境并安装依赖

需要 Python 3.10+。在项目目录执行：

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> 本项目依赖装在**项目自带的 `.venv`** 里，不依赖系统 Python，也不怕其他项目干扰。  
> `.venv` 不随仓库分发（体积大且与系统相关），clone 后请按上面两步自行创建。

### 2. 配置 API Key

在 [agnes-ai.com 官网](https://apihub.agnes-ai.com) 申请 Key，然后在 `.env`，填入：

```
AGNES_API_KEY=你的Key
```

`.env` 已被 `.gitignore` 屏蔽，不会进入版本库。**API Key 只存在于后端**，任何前端代码、日志、网络请求中都不会出现。

### 3. 启动

**一键启动（推荐）**：双击项目里的 `start.bat`——服务会自动启动，4 秒后自动打开浏览器。

**命令行方式**：

```bash
python -m uvicorn main:app --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 后，浏览器打开 **<http://127.0.0.1:8000>** 即可使用。

### 停止

在启动服务的终端按 `Ctrl+C`，或直接关闭窗口。

## 后端接口

| 方法与路径                      | 用途                        |
| -------------------------- | ------------------------- |
| `POST /api/image/text2img` | 文生图                       |
| `POST /api/image/img2img`  | 图生图                       |
| `POST /api/image/multi`    | 多图合成                      |
| `GET /api/files/<文件名>`     | 结果预览（`?download=1` 为附件下载） |
| `GET /api/health`          | 服务与 Key 状态自检              |

图像接口公共参数：

| 参数       | 取值                                                 |
| -------- | -------------------------------------------------- |
| `prompt` | 提示词（必填）                                            |
| `size`   | `1K` / `2K` / `3K` / `4K`                          |
| `ratio`  | `1:1` `3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` |

图生图额外传 `image`（公网 URL 或 Data URI Base64）；多图合成传 `images` 数组。

## 两个重要机制

### 1. 结果立即落盘

Agnes 返回的结果 URL **有效期仅数分钟**（实测约 3 分钟后失效）。因此后端在生成成功后会立即把图片下载到 `outputs/`，前端只与本地文件交互——刷新页面、关闭浏览器都不会丢结果。

### 2. 队列拥堵自动重试

Agnes 高峰期会返回 `503 queue is full`。后端会自动退避重试 3 次（20s / 45s / 75s），前端按钮显示「生成中（繁忙时自动重试）」。  
若持续拥堵，约 2–3 分钟后会返回明确提示，稍后再试即可——这是 Agnes 服务端容量问题，与本应用无关。

## 部署注意

- **API Key 必须留在服务端**：部署时通过环境变量注入 `.env`，不要把 Key 写进前端产物或提交到公开仓库
- 上线前建议补充：结果存储改为服务端持久化（对象存储等）、按用户维度的限流、多用户隔离
- 计费现状：Agnes Image 2.5 Flash 与 Video 2.5 Flash 当前限时免费，政策以官方公告为准
