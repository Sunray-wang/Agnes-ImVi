# Agnes 生成工作台

一个本地运行的 Web 应用，将 [Agnes AI](https://apihub.agnes-ai.com) 的图像与视频生成 API 封装为可视化操作界面。

**当前版本：`v0.2.1`**（2026-10-18 发布）· 版本更新记录见文末「版本记录」

当前阶段：**本地使用**（架构上已预留部署上线的条件，见下文「部署注意」）。

---

## 功能

### 图像生成（已可用，全部实测通过）

| 功能   | 说明                                |
| ---- | --------------------------------- |
| 文生图  | 文字描述生成图像，1K–4K 四档尺寸 × 8 种宽高比      |
| 图生图  | 基于单张输入图做转换、重绘、风格化编辑               |
| 多图合成 | 2–6 张参考图组合生成，按上传顺序在提示词中以「第 N 张」指代 |

### 视频生成（已上线，等待队列空闲即可生成）

| 功能 | 说明 |
| ---- | ---- |
| 文生视频 | 文字描述生成视频，固定 720P，时长 4–12 秒，6 种宽高比 |
| 首尾帧生视频 | 首帧必填 + 尾帧可选，生成帧间过渡视频 |
| 图生视频 | 1–5 张参考图，提示词中以「第 N 张」指代 |
| 音频参考 | 1–5 张图 + 1–3 段音频，提示词中以「第 N 张」/「音频 N」指代 |

视频任务为异步执行：点击生成后接口**立即返回**（毫秒级），后端在后台线程中排队创建（拥堵时自动重试），前端每 3 秒轮询进度，完成后自动播放并提供下载。轮询期间可以继续发起其他任务。

> **实测状态（如实说明）**：参数校验、轮询、落盘、错误处理已全部实测通过（冒烟 10/10）；真实生成链路受 Agnes 服务端制约——视频推理队列持续拥堵（`503 video_queue_full`），且免费账号有速率限制（`429 rate limit`），均会触发后端自动退避重试。数据 URI 输入支持情况的探测仍在后台进行（见 `test/test_video_probe.log`）。

## 快速开始

### 1. 创建虚拟环境并安装依赖

需要 Python 3.10+。在项目目录执行：

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> 本项目依赖装在**项目自带的 `.venv`** 里，不依赖系统 Python，也不怕其他项目干扰。  
> `.venv` 不随仓库分发（体积大且与系统相关），clone 后请按上面两步自行创建。

### 2. 配置 API Key

在 [agnes-ai.com 官网](https://apihub.agnes-ai.com) 申请 Key，然后在 `.env`，填入：

```
AGNES_API_KEY=你的Key
```

`.env` 已被 `.gitignore` 屏蔽，不会进入版本库。**API Key 只存在于后端**，任何前端代码、日志、网络请求中都不会出现。

### 3. 启动

**一键启动（推荐）**：双击项目里的 `start.bat`——服务会自动启动，4 秒后自动打开浏览器。

**命令行方式**：

```bash
python -m uvicorn main:app --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 后，浏览器打开 **<http://127.0.0.1:8000>** 即可使用。

### 停止

在启动服务的终端按 `Ctrl+C`，或直接关闭窗口。

## 后端接口

| 方法与路径                      | 用途                        |
| -------------------------- | ------------------------- |
| `POST /api/image/text2img` | 文生图                       |
| `POST /api/image/img2img`  | 图生图                       |
| `POST /api/image/multi`    | 多图合成                      |
| `POST /api/video/text2video` | 文生视频                    |
| `POST /api/video/keyframe` | 首尾帧生视频                   |
| `POST /api/video/reference` | 图生视频 / 音频参考             |
| `GET /api/video/status/<video_id>` | 视频任务状态轮询（completed 时自动落盘） |
| `GET /api/files/<文件名>`     | 结果预览（`?download=1` 为附件下载） |
| `GET /api/health`          | 服务与 Key 状态自检              |

图像接口公共参数：

| 参数       | 取值                                                 |
| -------- | -------------------------------------------------- |
| `prompt` | 提示词（必填）                                            |
| `size`   | `1K` / `2K` / `3K` / `4K`                          |
| `ratio`  | `1:1` `3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` |

图生图额外传 `image`（公网 URL 或 Data URI Base64）；多图合成传 `images` 数组。

视频接口公共参数：

| 参数             | 取值                                          |
| -------------- | ------------------------------------------- |
| `prompt`       | 提示词（必填），reference 模式用「第 N 张」/「音频 N」指代媒体 |
| `seconds`      | 字符串 `"4"` – `"12"`（默认 `"4"`）              |
| `aspect_ratio` | `21:9` `16:9` `4:3` `1:1` `3:4` `9:16`（默认 `16:9`） |

首尾帧传 `first_frame`（必填）/ `last_frame`（可选）；图生视频/音频参考传 `images`（≤5）与 `audios`（≤3）。视频固定 720P。

## 两个重要机制

### 1. 结果立即落盘

Agnes 返回的结果 URL **有效期仅数分钟**（实测约 3 分钟后失效）。因此后端在生成成功后会立即把图片下载到 `outputs/`，前端只与本地文件交互——刷新页面、关闭浏览器都不会丢结果。

### 2. 拥堵与限速自动重试

Agnes 高峰期会返回 `503 queue is full`，免费账号还会触发 `429 rate limit`。后端对两种情况统一自动退避重试 3 次（图像 20s / 45s / 75s，视频 30s / 60s / 90s），前端按钮显示「生成中（繁忙时自动重试）」。  
若持续拥堵，约 2–3 分钟后会返回明确提示，稍后再试即可——这是 Agnes 服务端容量问题，与本应用无关。

## 版本记录

> **更新规则**：每次发布新版本，在本章节**顶部**追加一条记录（版本号 + 日期 + 变更要点），旧版本下移。

### v0.2.1 — 2026-10-18（创建体验优化）

- 视频创建改为**后台任务模式**：接口毫秒级返回 `job_id`，后端线程内排队创建（拥堵 30s/60s/90s 重试），前端卡片实时显示「排队创建中（拥堵重试第 N 次）」
- 创建请求超时从 120s 收紧到 45s（创建本应秒回，挂起就快速失败重试）
- 前端轮询间隔 2s → 3s（降低触发免费限速概率）；创建提交后按钮立即恢复，支持同时发起多个任务
- 冒烟测试升级验证秒回性：创建接口实测 0.02s 返回（此前同步模式需卡约 3 分钟）

### v0.2 — 2026-10-18（视频功能上线）

- 新增四个视频接口：`/api/video/text2video`、`/api/video/keyframe`、`/api/video/reference`、`/api/video/status/<video_id>`
- 视频任务异步轮询：前端创建后每 2 秒查状态，进度条实时显示，完成后自动落盘并播放
- 视频参数体系：固定 720P，时长 4–12 秒（字符串），6 种宽高比实时显示输出像素
- 首尾帧 / 图生视频 / 音频参考的媒体输入：Data URI 或公网 URL，含完整参数校验（≤5 图 / ≤3 音频 / 必填帧）
- 错误处理增强：429 免费账号限速纳入退避重试，并返回可读提示
- 测试脚本移入 `test/`：`test_video_probe.py`（数据 URI 支持性探测）、`test_api_smoke.py`（接口冒烟，当前 9/9 通过）
- 实测状态：校验/轮询/落盘链路全部通过；真实生成受 Agnes 队列拥堵与免费限速制约，待服务端恢复
